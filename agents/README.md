# EEF Agents

## Agenten

### master-agent
Orchestriert Anfragen und delegiert an spezialisierte Agenten.

### email-agent
Klassifiziert E-Mails, erkennt Aufgaben und erstellt Antwortentwürfe.

### crm-agent
Pflegt Kunden-, Projekt- und Aufgabenstatus.

### document-agent
Erstellt strukturierte Dokumententwürfe aus freigegebenen Vorlagen.

### website-agent
Prüft Inhalte und erzeugt Änderungsvorschläge.

## Grundregel

Kein Agent darf ohne explizite Freigabe:
- externe Nachrichten versenden,
- produktive Website-Inhalte veröffentlichen,
- Verträge finalisieren,
- sensible Daten an Dritte übermitteln,
- produktive Daten löschen.
