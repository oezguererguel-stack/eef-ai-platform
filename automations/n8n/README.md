# n8n Automationen

## Workflow 01 – Inbox

Trigger: neue E-Mail

1. Absender identifizieren
2. Kunde/Projekt zuordnen
3. Nachricht klassifizieren
4. Priorität und Fristen erkennen
5. Antwortentwurf erstellen
6. Freigabe prüfen
7. CRM-Eintrag aktualisieren
8. Wiedervorlage setzen

## Workflow 02 – Website Review

Trigger: wöchentlich

1. Seiten prüfen
2. Links prüfen
3. Aktualität bewerten
4. Änderungsvorschläge erzeugen
5. Freigabe einholen
6. genehmigte Änderung veröffentlichen

## Workflow 03 – Project Follow-up

Trigger: täglich

1. offene Aufgaben lesen
2. Fälligkeiten prüfen
3. ausstehende Antworten erkennen
4. interne Übersicht erzeugen
