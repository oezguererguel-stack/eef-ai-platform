# EEF Website

## Ziel

Die Website wird als Teil der EEF-AI-Plattform betrieben und soll Inhalte strukturiert, aktuell und kontrollierbar bereitstellen.

## Geplante Seiten

- Startseite
- Unternehmensberatung
- Finanzierungsvorbereitung
- Geschäftsanbahnung
- Projekte
- Über EEF
- Insights
- Kontakt
- Impressum
- Datenschutz

## Content-Workflow

Entwurf → interne Prüfung → Freigabe → Veröffentlichung

## Technische Optionen

- WordPress + REST API
- oder Headless CMS + modernes Frontend

Die endgültige Auswahl erfolgt nach Prüfung der bestehenden Website und Hosting-Umgebung.
